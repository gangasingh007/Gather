  All 3D Renders

  │ perspective, soft studio key- 
  │ lighting, matte clay-like     
  │ textures, clean minimal       
  │ composition, no text overlays 
  │ unless specified, strictly    
  │ matching the Gather palette:  
  │                               
  │ • Deep midnight violet base:  
  │ #1f1633 and #150f23           
  │ • Electric lime highlights:   
  │ #c2ef4e                       
  │ • Hot pink accents: #fa7faa   
  │ • Deep purple/violet          
  │ structures: #422082
